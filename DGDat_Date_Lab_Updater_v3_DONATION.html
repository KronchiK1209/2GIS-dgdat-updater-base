OFFLINE · GDF HEADER DISCOVERY LABORATORY

DGDat Date Lab Updater v3.0

Автоматически ищет CRC-заголовок и четыре согласованных поля дат в поддерживаемой структуре GDF. Работает с крупными файлами потоково: в память загружается только небольшой начальный блок.

1. Выбрать базу

Выбери исходную базу. Оригинал не изменяется.

2. Автоматическое обнаружение структуры

Формат
Ожидает файл
Контрольные суммы не проверялись.

Найденные C0 + uint16 кандидаты

Нет данных.
После загрузки здесь появятся найденные блоки и уровень уверенности.

3. Новая дата выпуска

Остальные три даты сдвигаются на сохранённые интервалы исходной базы: uad, ewd и ed.
Сначала выбери базу, прошедшую проверку.
Файл не сформирован.

4. Что умеет автоопределение

  • Проверяет GDF-сигнатуру и две CRC32 из общей схемы заголовка.
  • Самостоятельно находит конец CRC-защищённого блока перебором границы с инкрементальным расчётом CRC.
  • Находит все маркеры C0 + uint16 внутри защищённого блока и отбирает единственный кластер из четырёх дат.
  • Сверяет временные интервалы и показывает, какие байтовые смещения будут изменены.
  • Изменяет только четыре подтверждённых поля дат и два поля CRC. Остальные байты заголовка и payload копируются без изменений.
  • Если профиль неоднозначен или CRC не подтверждает структуру — останавливается без экспорта.
Ограничение: это автоопределение для семейства GDF с CRC-полями по общим смещениям 0x0E и 0x15 и кодировкой дат C0 + uint16 BE. Другие варианты DGDat могут использовать иную структуру. Для них утилита откажется от автоматического изменения; это не универсальная спецификация всех версий 2ГИС.
Локальная обработка в браузере. Для файлов 350+ МБ используется File.slice()/Blob без чтения всего файла в оперативную память. Меняются метаданные даты, не картографическое содержимое.
